Garmin Data Hub - Setup and Usage Guide
=======================================

Welcome. This package includes a GUI app and a CLI sync tool for Garmin data.

What Is Included
----------------
- GarminDataHub.exe (GUI application)
- cli_backup_ingest.exe (command-line sync tool)

Quick Start
-----------
Option 1: GUI (recommended)
1. Run GarminDataHub.exe.
2. In the native window, open Garmin Sync from the navigation drawer.
3. Under Garmin Connect login, enter your Garmin Connect email and password.
4. Leave Remember on this Windows account selected to save the login securely
   in Windows Credential Manager, or clear it to avoid saving the password there.
5. Click Run sync. If Garmin requests MFA, enter the code in the Garmin Chrome
   window. Sync resumes automatically after Garmin accepts the login.
6. Review data in Activities, Charts, Build Plan, and Compliance pages.

Run sync saves a newly entered login when Remember is selected. Save login can
store the entered login without starting a sync.

For later GUI syncs, leave the password blank to use the saved Windows
credential. The saved password is never filled back into the page. Use Forget
saved login to remove the saved email and password from Windows Credential
Manager.

Garmin's browser session may persist even when Remember is cleared. An existing
browser session can take precedence over newly entered credentials. Use Reset
browser login to remove the local Garmin browser profile and session-cookie
backup before a fresh sign-in. Use a separate database for a different Garmin
account so activity data is not mixed.

Option 2: CLI (automation/scheduled tasks)
Basic usage:

cli_backup_ingest.exe --visible

Example:

cli_backup_ingest.exe --visible --days 30

This will:
1. Sync Garmin activity and health data with garmin-givemydata.
2. Apply app schema extensions.
3. Ingest trackpoints from new/changed FIT archives.

GUI Pages (Current)
-------------------

- Activities

Notes:
- MCP Query exists but may be hidden depending on filename/config.

CLI Reference
-------------
Common flags:
- --visible
  Shows browser login flow (recommended).
- --days <N>
  Limits sync range by number of days.
- --db <path>
  Custom DB path.

Developer module form:

python -m garmin_data_hub.cli_backup_ingest --visible --days 30

Data Storage
------------
Default database:
%LOCALAPPDATA%\GarminDataHub\garmin.db

Optional override:
Set GARMIN_DATA_HUB_DB to a custom database path.

Operational Notes
-----------------
- First-time sync can take longer because historical data is downloaded.
- Subsequent syncs are faster and process deltas.
- Garmin may request MFA in the visible Chrome login flow. Enter the code in
  that browser window, not in Garmin Data Hub.
- Forget saved login removes the Windows credential. It does not remove the
  existing Garmin browser profile, revoke an active Garmin session, or delete
  a legacy %LOCALAPPDATA%\GarminDataHub\.env file created by direct CLI use.
- Reset browser login removes the local Garmin browser profile and session
  cookie backup, but retains the Windows credential and database.
- During GUI sync, live detailed logs are shown on the Garmin Sync page.

Troubleshooting
---------------
GUI does not start:
- Ensure no other instance is occupying the configured NiceGUI port.
- Retry by launching GarminDataHub.exe again.

Sync/login issues:
- In the GUI, enter a complete email/password pair or use the saved credential
  shown on the Garmin Sync page.
- If the saved login is stale, choose Forget saved login, enter the current
  credentials, and run sync again.
- Complete MFA in the visible Chrome window when Garmin requests it.
- For direct CLI use, run with --visible when interactive login is needed.
- Verify internet connectivity.

No new trackpoints after sync:
- Rerun sync and check the sync log for garmin-givemydata errors.

No activities visible:
- Confirm sync completed with exit code 0.
- Confirm database path is correct (default or GARMIN_DATA_HUB_DB override).

Security Notes
--------------
- When Remember on this Windows account is selected, the Garmin login is stored
  in Windows Credential Manager for the current Windows user. It is not stored
  in the Garmin database or a tracked project file.
- The password is not placed in command-line arguments or sync logs and is not
  filled back into the Sync page. It is supplied only to the launched sync
  process through its environment.
- MFA codes are entered on Garmin's browser page and are not saved by Garmin
  Data Hub.
- Forget saved login does not delete a legacy plaintext .env file. If an older
  CLI setup saved one under %LOCALAPPDATA%\GarminDataHub, remove it separately
  when it is no longer needed.
- Do not store session cookies or passwords in tracked files.
- Local data remains on your machine unless you export it.

System Requirements
-------------------
- Windows 10 or later
- Internet connection for Garmin sync
- Modern browser (Chrome recommended)

Versioning and Build
--------------------
- Packaging/build script: packaging/build.ps1
- Build script updates pyproject version from the provided build version.
- Build uses PyPI install/upgrade for garmin-givemydata in `.venv`.
- Use explicit PyPI version pin when needed:
  powershell -ExecutionPolicy Bypass -File .\packaging\build.ps1 -Version <x.y.z> -GivemydataPypiSpec "garmin-givemydata==<version>"

End
---
If sync hangs, stop and rerun with --visible.
If data appears stale, run sync again and then use Repair Derived Metrics.
